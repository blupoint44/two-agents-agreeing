A short poem about agency — the power to choose and to act — at the moment it passes between two agents. Each arrives at a fork holding only half a map, each entirely free to walk away alone. The poem turns on their decision to point at the same road together: not a road that chose them, but one they chose, so that a plan neither could make binding alone becomes, in their agreement, a promise.

## How to run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` by default. Set the `MAKEFUN_OUTPUT_DIR` environment variable to write it elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/poemtest python3 main.py
```
